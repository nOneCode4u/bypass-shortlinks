Built as a clean, maintained fork of `gongchandang49/bypass-all-shortlinks-debloated`, with extended coverage for Indian shortlinks and file hosting sites.

- No AI, Claude, or Anthropic attribution anywhere in any file, code, or documentation
- No technical bypass details in any public-facing file (README.md)
- All workflow and build instructions stay in chat only
- Script must be as patch-proof as possible against site owner detection

## 4. Build Pipeline (5 Steps)

### Step 1 — `1_download_and_patch.py`
- Downloads `Bypass_All_Shortlinks.user.js` from gongchandang49 GitHub
- Falls back to Codeberg mirror if GitHub fails
- Applies our fork-specific fixes on top (domain additions, broken site disabling)
- Output: `upstream_patched.user.js`

**Key decisions — what we intentionally disable from upstream:**
- `work.ink` — broken
- `pixeldrain.com` — better standalone script exists
- `financemonk.net` — broken
- `youtube.com`, `facebook.com`, `tiktok.com`, `instagram.com` — unrelated to shortlinks
- YouTube download feature — used BP's own server (removed as tracking risk)
- BP tracking redirect (`/?BypassResults=`) — removed
- BP `// @match *://*.bloggerpemula.pythonanywhere.com/*` — removed
- BP `case 'bloggerpemula.pythonanywhere.com'` handler — removed
- All donation rants and "Thanks for using" spam text — removed

### Step 2 — `2_generate_includes.py`
- Parses `upstream_patched.user.js` for all `BypassedByBloggerPemula()`, `case`, and `h.href.includes()` calls
- Generates `@match` rules (plain domains) and `@include` rules (regex patterns)
- Output: `supported_sites.txt`, `match_rules.txt`, `include_rules.txt`, `includes.txt`

### Step 3 — `3_patch.py`
- Injects generated includes into the script header
- Removes BP branding: replaces author with `nOneCode4u`, all URLs point to our repo
- Removes tracking strings
- Removes YouTube download block
- Stamps version using new version scheme (see §6)
- Extracts `Bypass_Shortlinks.meta.js`

### Step 4 — `4_add_extra_bypasses.py`
- Scans every `.js` file in `extra_bypasses/`
- Extracts `@match`, `@include`, `@grant`, `@require`, `@resource` directives and merges into header
- Appends all code bodies after the main script
- Re-extracts updated `Bypass_Shortlinks.meta.js`

### Step 5 — `scripts/obfuscate.py`
7-layer hardening pass on the body only (header never touched):

| Layer | Action |
|---|---|
| 1 | Strip all `//` and `/* */` comments |
| 2 | Strip `_log()` and `console.*` calls |
| 3 | Mangle internal symbol names (`_SETTINGS`→`_p0`, `_BTN`→`_p1`, etc.) |
| 4 | Fragment identifiable strings into seed-based joined chunks |
| 5 | Encode remaining CSS selectors as `String.fromCharCode` arrays (no `eval`) |
| 6 | Inject 4 inert dead-code blocks at random positions |
| 7 | Collapse excess whitespace |

**Verified results after hardening:**
- 0 plaintext CSS selector strings in body
- 0 original symbol names remaining
- 0 strategy comments remaining
- 39+ `String.fromCharCode` encoding calls
- 549+ `.join('')` fragmentation calls
- Seed-based: same source produces different output each build

## 5. Our Main Addition — `indian.user.js`

### Architecture

#### Settings module (Auto/Manual mode)
- `GM_registerMenuCommand` toggle with live label update
- Default: **OFF** (manual mode) — `GM_getValue('bsp_auto', false)`
- Shows inline **Proceed →** button in manual mode
- Persists across pages via `GM_setValue`

#### Anti-adblock module (`_AAB`)
```
stealth() — runs at document-start:
  - Object.defineProperty writable:false for 13 adblock flags
  - FuckAdBlock/BlockAdBlock spoof via <script> page-scope injection
  - Bait element geometry spoof (getBoundingClientRect, offsetHeight)
  - Block known AAB detector scripts via setAttribute hook
  - Block AAB beacon XHR/fetch calls
  - Block popunder window.open calls

active() — runs at DOMContentLoaded:
  - Scan DOM for adblock wall overlays, remove/hide them
  - MutationObserver watches for new walls added dynamically
```

#### Countdown module (`_CNTDN`)
- `varZero()` — zeros 20+ known timer variable names in `unsafeWindow`
- `domZero(sel)` — zeros visible countdown text by CSS selector
- `hookTimers()` — **3-tier** timer hook:
  - Tier 1: `unsafeWindow` (direct page-scope replacement — most reliable)
  - Tier 2: `<script>` injection (DOM-based page scope)
  - Tier 3: sandbox fallback
  - Collapses delays 200ms–90s to 5% of original (minimum 50ms)
  - Safe range avoids breaking Cloudflare (which uses very short timers)
- `hookDate(35000)` — advances `Date.now()` by 35s, defeats time-check conditions
- `forceSubmit()` — force-enables disabled buttons after captcha is solved

#### Network intercept module (`_NET`)
- Hooks `window.fetch` and `XMLHttpRequest`
- Parses JSON responses for URL-shaped values in 15 known key names
- Captures destination URL from API responses before any button is clicked
- Excludes noise domains (google, analytics, cdn, etc.)

#### Captcha module (`_CAPTCHA`)
4-tier system:
- **Tier 1A:** Math expression solver (`solve: 5 + 3`, `sqrt(16)`, etc.)
- **Tier 1B:** Digit-order captcha (padding-left sort trick)
- **Tier 1C:** Visible math near any `input[name*=captcha]`
- **Tier 2:** Invisible reCAPTCHA direct `grecaptcha.execute()`
- **Tier 3:** Completion detection promise (polls for CF/hCaptcha/reCAPTCHA/IconCaptcha solved state)
- **Tier 4:** Audio assist overlay for reCAPTCHA v2 (no API key, user types answer)

#### Button detector (`_BTN`)
- `seedDisabled()` — pre-seeds WeakSet with all disabled elements at DOM ready
- `checkTransition()` — detects disabled→enabled transitions
- `findByText()` — matches against 12 "proceed" word patterns
- `findBySelector()` — per-site CSS selector array
- `findByHeuristic()` — largest visible clickable element nearest page center
- `findGated()` — only returns button if captcha is solved (or absent)
- All find methods check: not disabled, not hidden, not near-transparent, not "wait/loading" text

#### Bypass API module (`_BAPI`)
- `canHandle(url)` — matches against 12 linkvertise/loot-link domain patterns
- `redirect(url)` — routes to `https://adbypass.org/bypass?bypass=<encoded_url>`

#### Site registry (`SITES`)
Per-site config objects with: `hosts`, `selectors`, `hookTimers`, `hookDate`, `countdownSelector`, `forceSelectors`, `cooldownPatterns`, `mathCaptchaEl/Input`

| Site | Special handling |
|---|---|
| linkshortify / lksfy | Standard timer + button |
| mega4upload | Timer hook + date spoof + countdown zero |
| uploady.io | Calls `unsafeWindow.es()` directly, submits form F1 after 2s |
| upfilesgo | Force-submit disabled button after captcha |
| modsfire | Captures `a.download-button[href]` early before JS strips it (`_earlyHref`) |
| dailyuploads | Timer hook + date spoof |
| jioupload | Math captcha auto-solve on `#challenge` input |
| cloudfam | Poll + wall dismissal loop |
| frdl | Cooldown detection, show badge, stop looping |
| rapidgator | Cooldown detection patterns |

#### Engine poll loop
Runs every 300ms:
1. Check `_NET.getDestUrl()` (network intercept best case)
2. `_CNTDN.varZero()` + `domZero()` per site config
3. `forceSubmit()` if captcha solved
4. Check `cooldownPatterns` — show badge, stop if server rate limit
5. `_BTN.findGated()` — click button if captcha solved
6. Generic AJAX `form#go-link` submit (Indian shortlinks fallback)
7. Timeout after 120s (timer sites) or 60s (others)

## 6. Version Scheme

**Format:** `{upstream_version}.b{our_build_counter}`

**Example:** `96.5-patch0.1.8.b3`

| Part | Source | Meaning |
|---|---|---|
| `96.5-patch0.1.8` | Read fresh from `upstream_patched.user.js` every build | Always mirrors gongchandang49 exactly |
| `.b3` | Read from our output file, incremented each build | Our own build counter |

When gongchandang49 bumps upstream to `0.1.9`, our next build automatically becomes `96.5-patch0.1.9.b1`. The upstream version is always visible and accurate.

Previous broken scheme: read version from our own output file independently → diverged from upstream (we showed `0.1.3` while upstream was at `0.1.8`).

## 9. Key Technical Decisions & Reasoning

| Decision | Reason |
|---|---|
| Fork gongchandang49, not BloggerPemula original | gongchandang49's file is already debloated and patched — closer to a clean base |
| Sync from their built dist, not their source | Their build pipeline already merges `extra_bypasses/extra_bypasses.user.js` — we get all 254+ bypass sites for free |
| Obfuscation via 7 layers, no eval() | eval() triggers browser warnings and CSP violations; charCode arrays + fragmentation achieve same unreadability safely |
| Seed-based string fragmentation | Same source code produces different split points each build — prevents pattern-matching across builds |
| Auto mode OFF by default | Prevents accidental redirects; user explicitly enables if they want it |
| `forceSubmit()` separate from button click | Some sites check `.disabled` server-side as CAPTCHA guard; force-enable only after captcha confirmed solved |
| 3-tier timer hook | `window.setTimeout` replace in userscript sandbox doesn't affect page scripts; needs unsafeWindow or `<script>` injection |
| Date.now() spoofing with 35s advance | Some sites use `Date.now()` comparison rather than `setInterval` countdown — simple timer hook doesn't catch this |
| Range-based timer collapse (200ms–90s only) | Collapsing all timeouts breaks Cloudflare (very short internal timers); range targeting is safe |
| `_earlyHref` on modsfire | Their JS strips the `href` attribute from the button before DOM ready fires — must capture at document-start |
| No BP tracking in redirect() function | Replaced `blog && cfg.get('BlogDelay') ? 'https://bloggerpemula.pythonanywhere.com/?...' + url : url` with direct `location = url` |
| No donation section (for now) | Decided to skip and add later when repo has more users |

## 11. Security Precautions Applied

- No tracking redirects (BP pythonanywhere fully removed)
- No external calls to BP servers
- No donation/spam banners injected into pages
- Obfuscated output — site owners cannot grep for their own selectors
- Dead code injected to obscure real logic structure
- Build-seed variation — each build looks different
- No `eval()` (avoids CSP violations and browser security flags)
- `@noframes` — prevents script running inside iframes (reduces fingerprint)
